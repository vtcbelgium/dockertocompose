Convert 'docker run nginx' to Docker Compose

Transform the standard Nginx web server command line into a robust, repeatable compose.yaml specification.

Original CLI Command:

docker run -d --name my-nginx -p 80:80 -p 443:443 -v ./html:/usr/share/nginx/html:ro -v ./nginx.conf:/etc/nginx/nginx.conf:ro --restart always nginx:alpine

Equivalent compose.yaml:

services:
  nginx:
    image: nginx:alpine
    container_name: my-nginx
    restart: always
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./html:/usr/share/nginx/html:ro
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
